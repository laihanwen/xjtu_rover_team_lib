# 八推矢量 ROV 工程开发目录

本目录负责实机固件的后续修改，不存放论文数据和临时优化脚本。

## 有效入口

- Keil 工程：`MDK-ARM/Copy_cup.uvprojx`
- 八推混控与遥控：`MDK-ARM/Move.c`
- 姿态 PID、动态去饱和和 PWM：`MDK-ARM/Mate.c`
- 安装与控制说明：`MDK-ARM/Move_Manual.md`
- 编辑器代码模型：根目录 `CMakeLists.txt`、`CMakePresets.json` 和 `.vscode`

`Core/Src/Move.c`、`Core/Src/Mate.c` 等同名文件是历史副本，不在当前 Keil 自定义控制编译链中。

## 当前构型基线

- 坐标系：`+X` 前、`+Y` 左、`+Z` 上；重心为原点。
- 安装坐标：八个 `(±112, ±136, ±70) mm` 顶点。
- 推力方向绝对分量：已发加工构型 `(0.418094,0.418094,0.806470)`。
- 基础锐角：`(65.29°,65.29°,36.25°)`；逐台实际尾流三轴夹角见 `MDK-ARM/Move_Manual.md`。
- 运行时矩阵：归一化伪逆符号乘经典八推匹配增益 `[0.85,0.85,0.62,0.85,0.47,0.85]`，系数保留两位小数。
- 控制顺序：先形成唯一六维动力输入，再执行一次八推分配和一次公共动态缩放；没有 60% 六维限制。
- 保持项：遥控映射、PID、PWM 和推进器极性。

## 修改要求

1. 先在论文研究目录完成配置矩阵生成与满秩校验。
2. 修改 `MDK-ARM/Move.c` 后同步更新 `MDK-ARM/Move_Manual.md`。
3. 每次交付前使用 ARMCC5 全量重编译，目标要求为 `0 Error(s), 0 Warning(s)`。
4. 未经单推进器低功率方向确认，不进行多自由度水下测试。

论文研究目录位于同级的 `../八推矢量_论文研究`。
