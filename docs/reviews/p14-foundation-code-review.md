# P14 视觉基础代码审查记录

审查范围：`ValveDetection` 接口、OpenCV 检测器、ROS 节点、bringup 参数与启动文件、
自动测试和运行文档。审查日期：2026-10-03。

## 结论

在“转盘视觉基础环境”范围内，没有遗留已知的高风险或阻断问题。当前实现可用于合成图、
摄像头和离线录像的算法开发，但尚不能作为比赛闭环完成证明。

## 审查中修复的问题

1. 把手直线原先在整幅图上搜索，背景边缘可能造成错误角度。现已将搜索限制在候选圆内部，
   并要求线段端点位于圆内。
2. 浮点参数原先没有明确拒绝 NaN/Inf。现已补充有限值校验，非法参数会让节点安全退出。
3. 高频相机输入会让树莓派逐帧执行 Canny/Hough。现增加独立 `processing_rate`，默认
   15 Hz，不影响摄像头视频话题帧率。
4. 增加非圆矩形、纯圆无把手、多个代表角度和 ROS 发布链路的回归测试。

## 已验证的能力

- 空图输出 `detected=false`。
- 明显非圆轮廓被拒绝。
- 合成圆盘中心、半径和水平/倾斜把手轴线可检出。
- 纯圆不会输出虚假的把手角度。
- ROS 图像输入可以产生 `/valve/detection` 和 `/valve/debug_image`。
- `system.launch.py start_valve:=true` 可以加载安装后的 YAML 并启动节点。
- P14 默认关闭，不会发送运动或执行器命令。

## 尚未被证实的能力

- 真实比赛转盘和水下光照条件下的准确率。
- 镜头畸变、悬浮物、反光、遮挡和倾斜视角下的鲁棒性。
- 树莓派 4B 实机 CPU 占用和持续温度；15 Hz 只是保守起点。
- 旋转方向、跨越 ±90° 的连续角度展开和累计旋转 180°。
- AUV 对准、接触、执行器驱动和任务闭环。

因此当前节点只允许作为观测源。进入控制闭环前必须按
[`p14-valve-foundation.md`](../testing/p14-valve-foundation.md)采集真实数据并完成门槛项。
