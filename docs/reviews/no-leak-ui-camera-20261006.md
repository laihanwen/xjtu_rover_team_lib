# 无漏水硬件配置与控制页面更新

操作者明确当前系统没有漏水检测，已移除STM32安全上下文、输入API及故障分支，任务FSM与路线执行判断、状态解码和ROS Stm32Status中的对应字段。CRC数据包布局不变，旧状态bit1与错误bit2不再由新版固件设置。急停、心跳、传感器失效、默认DISARM、显式ARM与输出限幅仍保留。相关ROS消息变更需要重新编译ROS工作区。

PID保留操作者要求的十倍增益。Keil0错误0警告，14项固件宿主测试及5项桥接测试通过；任务FSM、状态解码器通过MSVC C++17编译，独立FSM烟测验证正常状态可以通过自检，传感器错误和运行中断连仍进入FAULT。完整ROS与Linux轻量runtime未在本Windows环境编译运行，新增双摄CSI下视断流/恢复测试尚未执行。

遥控网页改为姿态/延迟指标、明显的ARM/STOP按钮、手柄进度条和折叠遥测；自动任务网页改为阶段/帧率/航点指标、双摄画面和九宫格。已在隔离浏览器预览检查窄屏及桌面布局；预览所有POST被拒绝，不连接实际串口。build/rov-ui-preview.png、build/mission-ui-preview.png为模拟数据效果截图。

摄像头物理安装已由操作者确认：CSI下视、USB前视。camera.source默认csi:0作为AprilTag/网格/交通锥主视觉；camera_front使用USB实际by-id设备，默认保持enabled=false，部署模板已有确定USB设备名并启用双摄。下视复用有界CSI MJPEG采集器，首帧等待8秒、断流2秒重启，独立USB前视和控制线程。HLS左下视右前视，页面标注同步更新。需实机验证串流、安装方向、相机内参和算法目标识别；原USB内参不能当作CSI内参。

本次仅修改与本地编译/预览，未烧录STM32或部署树莓派。先前设备连接失败状态尚未被新的实机成功结果替代。
