# 机械爪启动输出与小幅自检（2026-10-06）

用户现象：舵机每次启动大幅开合，希望每次开机进行一定角度开合自检。

## 已确认与修改

此前未标定固件也启动PA8/TIM1_CH1并持续输出1500μs。1500μs对位置舵机是绝对位置目标，不能当作“无动作”；机构若停在其他位置，首次脉冲可能引发大幅移动。此前标定版本还自动以限速方式走到close_us端点。以上是代码行为，不证明舵机自身启动、供电或机械安装没有其他问题。

- 未标定/无效配置不启动夹爪PWM，避免固定中位位置指令。有效标定也不再自动全程关闭。
- 新增一次性boot自检：配置启动位置→启动等待→限速移到自检位置→停留→限速返回启动位置。起点和自检位置必须在已标定close/open机械端点内。
- `AuvGripperConfig.h` 新增BOOT_TEST_ENABLED、BOOT_START_US、BOOT_EXCURSION_US、BOOT_WAIT_MS、BOOT_HOLD_MS。默认启用门为0，位置是TODO占位0，不猜度数/PWM。等待默认1000ms、停留300ms；已有每控制周期10μs斜率用于运动段。
- STOP、急停、漏水或ARM取消自检，不自动重试；自检期间拒绝远端运动目标。独立自检授权不ARM推进器。无效配置禁用输出，STOP不能重新开启未标定输出。
- 调试器可读取 `active_status.boot_test_state` 的WAIT/OUT/HOLD/RETURN/COMPLETE/CANCELLED；现有执行器线协议没有增加字段。

## 验证与局限

宿主11/11通过，其中机械爪测试覆盖启动不全程闭合、小幅往返、等待/停留、时间戳回绕、只执行一次、取消、端点越界和未标定禁用；Keil0错误0警告。PWM动作测试使用合成配置，不是实际舵机标定。

无位置反馈舵机不能读取断电前实际角度。限速只约束连续输出脉宽变化，不能保证首次收到绝对位置指令后的物理移动很小。执行序列完成也不能证明舵机实际到位或未卡滞。若断开PWM仍大幅运动，需检查舵机内部上电行为、供电与信号线路。配置自检前仍需确认实际型号（代码记录T35-L）、卸载状态、实测安全位置及所需开合角度。

本次请求已发出参数问题；尚未收到答复，实际小幅运动自检保持禁用。默认输出禁止版可以通过TIM1 CCER CH1使能位为0验证，不靠CCR显示1500μs来判断是否有PWM。
