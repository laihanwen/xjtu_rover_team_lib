# ROV 手柄低速试用部署（2026-10-06）

用户明确要求禁用舵机、试用ROV手柄控制，并希望推进器实际动作；确认推进器可靠固定、周围安全、允许短时空转、具有硬件急停装置；确认深度计由STM32读取。只有深度传感器，没有确认安装漏水传感器，因此页面明确显示无漏水传感器，不宣称完整自主安全配置已完成。

## 当前部署

- STM32手动试用模式：`AUV_ROV_MANUAL_TRIAL=1`；USART1/H30 460800，USART2/Pi CRC 115200，USART3/M10 115200。切换回0才恢复以前USART2旧A5、USART3自主CRC的模式。
- 两路舵机标定门为0、机械爪boot自检为0，实机TIM1/TIM8 CCER都为0。CRC遥控帧强制舵机输入127、选择2，航向/深度开关0。
- 仅手动surge/sway/heave/yaw。姿态补偿关闭，定深关闭，自主motion-target命令被拒绝，避免初次检查未确认的推力方向时姿态闭环自行纠正。
- 中位1492（用户实测），八推公共输出偏移上限±50计数；这只是软件低速限幅，不等于已测ESC死区或实际推力。用户已取消固定运行时限；左肩许可、STOP、通信和惯导超时停机仍有效。
- 上电remote kill默认置位。必须新鲜有效IMU、四轴回中、左肩许可、有效CRC遥控输入、心跳后显式ARM；控制源锁定RC。软件停止、左肩拨回、手柄/网络/浏览器掉线会DISARM；重连不自动ARM。
- 沿用IMU250ms、RC250ms、心跳500ms门；Pi客户端输入200ms失联，Pi发出的挑战250ms到期，过期/重复网络包不能延长控制新鲜度。
- 手动试用不使用深度闭环，深度无效不禁止手动升沉；这项例外仅限本手动profile，不用于自主定深任务。IMU失效仍阻止ARM并停机。

## 协议与服务

新增CRC消息0x05：sequence(u32 LE)+已清除舵机/保持输入的11字节RC帧+deadman(u8)；0x06：remote kill(u8，0/1)。0x02仍为显式ARM/DISARM。CRC仍为CCITT-FALSE，原来的裸A5工具不兼容此试用服务。

Pi `auv-rov.service`增加 `30-manual-trial.conf` drop-in，使用 `/usr/local/lib/auv-rov/trial_server.py`，绑定192.168.137.150:8888；通过dialout和DevicePolicy仅开放实际ttyS0串口。轻量runtime仍serial=false、auto_arm=false，双摄功能继续运行，不与ROV串口抢占。

PC入口 `tools/rov/Start-RovTrial.ps1`，本机控制页 <http://127.0.0.1:8767/>；仅浏览器本机Origin可调用ARM/STOP，读取网页和接入手柄不会自动ARM。当前页面有实际STM32姿态/输出、串口CRC计数、手柄四轴/许可/回中状态。

用户纠正后左肩对应axis5，原始值≥+0.5为运行许可；这是一个许可位置，未宣称开关有弹簧回位。必须人工拨回其余位置，或使用网页STOP/Esc/硬件急停。速度固定旧SC慢档，右肩暂不改变速度；SA/SD保持开关暂禁用。

## 开始与停止

1. 打开本机控制页，保持推进器固定，硬件急停可立即操作。
2. 四轴回中，左肩拨到许可位，确认界面显示允许/回中，点击“ARM · 低速试用”。
3. 一次只小幅移动一根轴，观察真实方向，无固定运行时限；方向异常立即STOP并反馈轴/方向。
4. 点击STOP或Esc、左肩拨回、关闭页面均停止；不要把软件停机替代硬件急停。

重启PC入口：`powershell -NoProfile -ExecutionPolicy Bypass -File tools/rov/Start-RovTrial.ps1`。停止Pi遥控服务：`sudo systemctl stop auv-rov`；MCU缺少心跳/遥控帧后进入安全停机。撤回drop-in可恢复Pi旧预览服务，但固件仍为试用profile，不能因此宣称恢复了完整自主模式。
