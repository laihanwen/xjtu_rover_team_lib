## 2. 真实素材与识别验证

- [ ] 用现有素材建立锥体/底座分离真值，训练并验收灰度 body ONNX 方案 B；颜色 A、形状 B、agreement 软件选择器已实现，B 未有真实验收权重，不解除运动门。
- [ ] 在 Ubuntu 验证本轮 HTTP boot 字段及完整 Runtime；同钟记录/关联软件已实现，部署后检查 Pi boot、MCU epoch、有效标记和运输延迟，不能按旧日志恢复未记录的数据。见[本轮软件记录](testing/dual-vision-sensor-development-20261012.md)。

- [ ] 用已选高清帧验证局部管线、接头及格号关联，处理瓷砖干扰、平移和旋转歧义，不以放宽完整四角门替代局部算法。
- [ ] 完善红白条纹合并、整锥与底座分离，核验圆/方类别、格位和轮廓；证据不足保持 unknown，人工 ROI 不当作自动识别结果。
- [ ] 补齐必要像素真值：标签 ID、管中心接头、锥体/底座轮廓及逐帧格位；遮挡、画外及不完整格不能判 empty。
- [ ] 对人工可见但未解码的标签帧按模糊、遮挡、倾斜和像素尺寸归因；已有加密采样补人工真值，改进后使用同一批真值回归。
- [ ] 用同版 C++ 局部检测与锥检测回放真实素材，输出黄边方向、类别、格位、轮廓及拒绝原因；现有完整外框拒绝结果不作为局部验证。
- [ ] 建立经过真值验证的空格地板颜色模型，仅将完整可见且证据充分的格判为 empty。
- [ ] 利用已采集的原始双摄录像与同期日志核验重叠视野、黄边、四锥、L/T/十字回访、上浮及出口；建立实际帧与传感器时间关联，不补造米制数据，暂不要求新增补录。
- [ ] 用同步素材检验遍历期间局部地标覆盖、里程计漂移、最长失效时间和重定位唯一性，不要求前视连续看到全图。

- [ ] 落实视觉角点定义，区分标签黑边角点、管中心接头和网格外缘，确保世界坐标与像素观测对应一致。

- [ ] 整理已验证 yaw 数值映射及深度归零原始记录，核对 AUV 配置；已确认口径不重复测试，未提供数值不猜填、不重复扣零。
- [ ] 核验水下与上浮后实际图像空间、尺寸、K/D 和外参一致性，验证对应阶段的成像几何。
- [ ] 以已保存的双摄 640×480 参数开展独立测距/导航验证，绑定实际原始素材与阶段模型；显示确认不代替几何验收。仅在验证发现误差时补标定素材或重标，不重复要求已完成的参数采集。
- [ ] 验证新增离网格控制：测量机体包络/净空并指定允许出口，核验新阶段重定位、实际越界确认及失败保护；源码已实现，尚未在完整 Runtime 或水池验收。
