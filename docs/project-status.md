# 当前项目状态

更新：2026-10-11。本次已核对 Pi 两服务恢复运行，旧部署证据仍按其记录日期解释，操作前重新核查。源码实现、软件回归、部署与水池验收分别记录。

## 当前运行路线

ROS 暂时归档；自动研发使用 core/ + runtime/ 轻量系统。ROV/AUV 使用独立固件和匹配的 Pi 服务，单固件会话切换已停用。ROV 桥独占 UART，摄像头 Runtime 串口为空、运动关闭；AUV Runtime 独占 UART 时不得同时运行 ROV 桥。

## 当前阻碍

1. 完整四角在真实素材中无法持续观测；需要局部接头、锥体轮廓和连续双摄/遥测数据，不能从摆放模板填图。
2. A2 动态仿真仍失败，发生过陈旧定位或位姿跳变；安全门未放宽。Pi 欠压降频且仿真与摄像头进程并行，先解决供电及隔离运行条件再验收。
3. 未提供的数值偏航转换、实测深度零点不猜填、不重复扣零；原始负读数保留证据。
4. 高清原图不能直接用于现有低分辨率几何模型；上浮阶段、遍历连续定位和水池净空独立验收。
