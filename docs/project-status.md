## 下一阶段顺序

1. 恢复Pi连接，核验双摄来源和服务版本，部署优化Runtime；测双路独立/并发预览、录制FPS和断流收尾。

3. 分轴水下验证航向/深度纠正方向与回中重锁，再验证混动；保留稳定姿态参数。
4. 按实机日志分析饱和、补偿比例和定深摆动，再决定参数调整或代码拆分。
5. 采集水下训练数据，推进自主任务标定和验收。
