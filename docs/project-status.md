更新：2026-10-10。源码、编译验证、历史部署和实机验收分别列出；不根据本页推断设备此刻在线或安全。

## 当前路线

使用 `core/` + `runtime/` 轻量 C++ 系统，ROS 暂时弃用。ROV/AUV 固件及驾驶台分开；双模式会话交接已弃用，切换需对应固件和 Pi 服务。ROV 保留原控制与连续 MJPEG 双摄，AUV 负责自主开发，默认运动/自动 ARM 关闭。

## 当前阻碍与下一步

1. 用原始录像时间索引关联遥测；剪辑视频不能套固定起始时间。此次 3890 条诊断记录定位均为 calibration_required，存在负压力读数，不能自动当作标定证据。
2. 验证前视实际 K/D、固定云台角外参、场地尺度和连续视场覆盖，再迁移建图及绝对定位输入。
3. 若完整网格不持续可见，开发并验证绝对视觉修正与局部里程计融合；不能用时长、预设地图或动作发送代替确认。
4. 实测水面/池底净空与锥高，使用不露出水面的遍历深度；在默认门控下先无动力验证，再受控下水。
