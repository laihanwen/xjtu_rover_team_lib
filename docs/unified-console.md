# AUV / ROV 统一驾驶台

统一页面位于 `runtime/web/dashboard/`，集中展示双摄、深度与姿态、标签任务阶段、安全许可、记录证据、推进器遥测及事件。

## 虚拟检视

在仓库根目录运行：

```powershell
python tools/console/preview.py
```

访问 `http://127.0.0.1:8769/dashboard/`。选择稳定悬停、标签接近、深度测试、目标丢失或安全待命；顶部 ROV/AUV 按钮演示交接，确认后保持 DISARM。目标丢失演示在两秒后显示 FAULT 和 DISARM。可暂停或导出标记为 `VIRTUAL_DEMO` 的 JSON 检视快照。

所有图像为合成画面，参数为虚拟值，包括标定许可、深度报告、九宫格与推进器输出。它们不代表实机能力或验收。此进程仅监听本机，GET 仅允许页面资源与演示配置，POST 返回 405；不访问串口、SSH、手柄或机器人。

## 实机入口

ROV 原驾驶台后端与 AUV Runtime 分别提供 `/dashboard/`，共享页面由 `/dashboard/config` 选择真实数据源。获取配置失败不会回退到演示数据。未提供的遥测显示为 `—`；断流显示遥测过期，不能据此宣称已 DISARM。

ROV 保留原根页面、操纵面板、安全许可、回中和显式 ARM 门控；统一页通过弹窗打开原操纵面板。AUV 页面只读，显示现有 Runtime 状态和共享相机快照，不新增 HTTP ARM 或任务控制入口。实机模式按钮仅展示已有 `switch_mode.py` 交接命令，不在浏览器执行；真实交接仍要求默认 DISARM 和 UART 单一所有者。

当前统一页按标签接近测试设计。九宫格仅在演示中出现；正式建图与遍历视图尚未接入。完整 Runtime 修改需在 Linux 重新编译验证，本轮未部署或烧录。

## 双模式双摄录像

两种模式均保留前视与下视记录。ROV 的“开始双摄录制 / 停止双摄录制”复用现有 `/recording` PC 记录器，显示两路帧数和实收 FPS，保存独立 MJPEG AVI、时间戳及图像空间/标定元数据，不重新打开相机。AUV 按配置自动记录两路原始帧，统一页显示记录启用状态、就绪状态、目录及错误；保持只读，不提供任务期间停录按钮。

演示中的录制按钮仅切换虚拟状态，不产生实际视频文件。模式交接会停止原服务并建立新会话，当前不承诺跨模式无缝录像；ROV PC 录制应在切换前结束并在交接后按需开始新会话，AUV 从新 Runtime 会话自动开始记录。录像操作不改变 ARM 或运动目标。

JavaScript 语法检查通过；ROV Python 回归共 36 项，35 项通过，1 项可选视频解码测试跳过。虚拟服务已验证配置、资源、POST 禁止、真实 API 不可访问和路径越界拒绝；浏览器核验目标丢失后 FAULT/DISARM、模拟切换后中立待命及双摄布局。
