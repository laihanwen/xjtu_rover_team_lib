# ROV 驾驶台数据采集

更新：2026-10-11。最后实机配置为独立 ROV 固件，使用驾驶台 http://127.0.0.1:8767/#collection-panel 。一键烧录启动见 [入口说明](one-click-flash-console.md)。

## 本轮采集

优先局部管线/接头、四锥完整轮廓、连续双摄与重访；其次上浮视野与困难标签。拍摄步骤和时长见 [采集清单](testing/next-data-collection-20261010.md)。原有深度/标定/安装项目保留为可选工具，不要求重复采集已确认参数。

1. 确认现场安全，开启双摄预览与录制。
2. 选择项目、填写备注。已确认池深1.4 m、前视俯角45°；实际当前深度未知留空，不能把1.2 m作业上限当池深。
3. 开始定时采样，默认180秒，可设10–600秒。每个接头、锥体、重访位置标记阶段。
4. 分别结束采样与录像，等待保存完成。导出采样 JSONL，保留原始录像与逐帧索引。

无手柄时驾驶台仍可读取桥接遥测，发送中立帧、安全许可关闭并忽略操作请求；有手柄后沿用显式 ARM 门控。仅需只读页面可用 Start-Data-Collection.cmd（8768），该模式不连接控制桥，Runtime串口为空时不能用其状态代替 MCU 遥测。

## 数据与验证边界

采样每0.5秒记录接收快照、有效性、来源、UTC/单调时间、阶段备注及录像关联，实际频率以时间戳为准。诊断日志每0.1秒读缓存，不能当作 MCU 的独立10 Hz测量。PC/Pi单调时钟不能直接相减；双摄索引需核对，不宣称硬件同步。

录像及采样保存 data/rov-recordings/，普通与诊断日志保存 logs/rov/。下视640×480原图、前视320×240矫正；离线按会话图像空间处理，禁止二次矫正或套用不匹配内参。原始负深度保留，不自动再次扣零。

最近 ROV 工具44项通过、1项跳过；无动力双摄录像与采样保存验证见 [部署记录](testing/rov-data-collection-deployment-20261010.md) 和 [高清下视](testing/rov-hd-down-20261010.md)。实机运动与导航闭环仍须独立验收。
