# ROV 驾驶台试验数据采集助手

原驾驶台双摄区域下新增助手，支持深度计/零点、前视标定、标签交接、安装尺寸与受控运动响应记录。复用原连续 MJPEG 预览和双摄录像，不增加相机采集或改动 MCU、Pi 服务、遥控混控。

当前实机为独立 AUV 固件，双击 `tools/rov/Start-Data-Collection.cmd` 打开 `http://127.0.0.1:8768/` 的只读采集模式。该模式不连接 ROV 控制桥，后端拒绝所有控制与原点重置请求；可读取当前 AUV Runtime 状态并复用双摄预览/录制。不能把此入口当 AUV 急停；实机停止使用匹配 AUV 的 `auvctl disarm`。恢复 ROV 遥控需独立固件及服务，本文入口不执行烧录。

使用步骤：

1. 在现场确认推进器断电或可靠固定。需要视频时，先开启上方双摄预览和录制。
2. 选择采集项目，填写**实测**深度、池深、固定俯角、阶段备注；未知值留空，1.2 m 上限不能填作池深。
3. 勾选现场确认并开始定时采样。默认 30 秒，可设 10–600 秒。水面静止先采 30 秒，随后每个人工测量深度静止采约 20 秒。
4. 双摄交接录像中人工搬运机器人，按“前视可见—交接—下视居中”修改备注并标记阶段；标记含人工测量值、UTC 和单调时间。
5. 时长到达或手动结束后导出 JSONL。采样结束不会停止双摄录像，录像另行结束保存。

后台按名义 0.5 秒周期保存，不依赖网页持续打开；网络请求、写盘耗时会降低实际采样频率，以记录时间戳为准。采样记录包含完整 ROV 遥测/定位快照或 Runtime 状态、来源、接收时间、录像目录与帧数。无有效深度、遥测过期等如实保存，人工实测值作为独立注释，不覆盖传感器数据。不自动计算标定结果或打开验证标记。

记录位于默认 `data/rov-recordings/collection/时间/samples.jsonl`，视频仍由原录制器保存。两类记录都有时间索引，但不是硬件同步；精确双摄同步需按已有录像索引核验。浏览器导出最近已结束的采样记录；历史记录在 PC 目录保留。安装照片及标定板素材另行保存，备注可填对应文件名。

普通 ROV 模式使用最新原驾驶台进程即可显示此助手；正在运行的旧进程需在停止遥控和录制后重新启动。采集新增四项测试均通过；ROV 全部 Python 测试 40 项中 39 通过、1 项可选独立解码器测试跳过。浏览器验证采集表单存在、未确认采样拒绝、只读 ARM 请求拒绝；本次未进行实机运动采集、ARM 或固件切换。
