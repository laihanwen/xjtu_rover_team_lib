## 软件检查

使用已有完整 Linux 构建，兼容 fish：

```fish
cmake --build build-native --target auv_runtime auvctl test_tag_docking -j 2
ctest --test-dir build-native -R '^(tag_docking|tag_docking_simulation|runtime_pty)$' --output-on-failure
```

标签虚拟测试只使用 PTY 与合成录像。独立压力序号每 0.55 s 更新，不以 STATUS 接收次数冒充压力更新；进入 HOVER 后停止压力发送，必须 FAULT 并收到 DISARM。通过不代表真实 PID、视野交接或导航验收。

Windows 构建固件：

```powershell
./tools/auv/Build-AuvFirmware.ps1 -Profile AUV_TAG_DOCK
```

固件主机测试必须覆盖急停断言、拒绝未许可/ARM中清除、格式拒绝、心跳超时与不自动再ARM。未标定默认固件继续拒绝自主 ARM。

## 统一实机检查顺序

1. 保存当前配置/版本，确认机体受控固定、桨区无人或动力断开。通过现有准备流程确认 DISARM、八路中立、停止互斥控制服务。
2. 烧录与全读回校验；部署同版已通过 Linux 检查的 Runtime，并保留当前实测配置。不能使用 ROV 摄像头服务代替标签任务串口链路。
3. 只启动 debug 待命，保持 auto_start=false、auto_arm=false。用原生配置检查与 Tag-Test 检查核对固件记录一致性。
4. 无动力验收：放平完成水平参考；确认压力采样在真实浸水位置有效，水面零点 -0.05 m，Runtime 不重复扣零；两相机与记录器新鲜，yaw 符号 +1。原点、启动姿态、启动深度必须满足程序条件。
5. 将 ID18 完整放入画面，先观察前视/下视检出、裁剪拒绝原因及像素中心误差；确认相对位置与实测距离/方向一致。标签尺寸 138 mm、前视安装45°和已提供位置沿用已有证据，不重复采标定板。
6. 安全固定下标定自主 surge/sway 增益和升沉方向/定深响应，沿用已验证混控与中位；仅该阶段验证通过后填写对应标定项，不能套用未知增益。0.5 m 接近范围仍需实际净空验收。
7. 完整启动缺项清空后才请求任务和显式 ARM。先短时定深，再接近与下视交接，最后悬停；单项失败应保留证据后停止，不自动重试。
8. 检查显式 DISARM、压力丢失、标签持续丢失、控制超时后的停止行为。真实通信失效测试先无动力完成；软件急停不替代独立物理断电措施。

驾驶台显示 startup_blockers 和独立压力超时参数。它是就绪诊断，不是权限开关。停止命令应使用当前 systemd ExecStart 所在发布目录中的 auvctl，不能假定 /opt/auv-tag-docking/bin 存在。
