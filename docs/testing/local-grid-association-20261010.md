# 局部网格关联核心

`local_grid_association.hpp` 输入已验证的管中心节点整数格距、N/E/S/W 分支、已经检查的方向、黄色分支及置信度。尚未实现从像素候选生成这些输入；不能将 Hough 交点直接视作真实节点。

对 4×4 管中心节点格枚举平移和四种旋转。遮挡方向不作为缺失分支；黄边在规范坐标中为底边。多个解保留 ambiguous，没有解报告拓扑/黄边冲突。只有唯一解才可进一步关联语义证据；不输出米制位姿或场地航向，也不猜镜像。

Windows MSVC C++17 和 Pi CMake Release 测试通过：单个十字接头有 16 个候选；遮挡 T 接头保持歧义；充分黄边/接头证据唯一对应；四种旋转、相互矛盾、重复节点和非有限置信度均有检查。

该模块和局部语义累积核心都未接入 Runtime。后续需要真实管中心线和接头分支真值、管/瓷砖排除、连续观测关联及地标/里程计融合，才能验收实际局部建图。
