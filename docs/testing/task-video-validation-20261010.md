## 人工标注

先在样图中确定哪些时间段完整看到标签、外框四角、黄边和四个锥，再对这些区间加密采样。表格中填写：标签可见 yes/no/uncertain；黄边图像侧 top/right/bottom/left/unknown；锥数；九格分别 empty/circle_cone/square_cone/unknown。空白表示尚未复核，unknown 表示画面不足以判断。遮挡不能标 empty，不能照预设摆放填答案。

更详细的参考标注还应包含原始像素坐标中的外框四角、锥体与底座分别的轮廓，以及标签可辨识/遮挡区间。若用人工四角透视变换评估锥分类，必须标明四角是人工输入，不能把结果算作自动建图成功。

## 后续正式算法回放

对同一画面运行正式 C++ 网格与锥检测，叠加角点、方向、轮廓、类别和拒绝原因，与人工标注对比。黄边四种方向均检查，规范地图转回真实视角后应保持目标对应关系。统计误检、可见区间漏检、稳定地图建立时间、每锥类别一致性、最长失效时段。当前 Python 筛查入口只检标签，不能报告正式九宫格或锥分类已通过。

现有 `auv_surface_replay` 读取机载 MJPEG、帧索引和遥测，入口会去畸变；不能直接把这批已矫正 MP4 转成 MJPEG 后送入它，否则会二次矫正。度量验证需先补齐图像空间、裁切/缩放对应关系、同步深度和实际参考位置。剪辑视频按原始帧号分段对齐，不凭片头时间强行对齐日志。

## 锥形状方案

现有 ConeDetector 对分格后的颜色外轮廓使用圆度、多边形近似和填充率分类，并保存轮廓。建议保留网格定位链，把形状证据分成：前视锥体侧面、下视顶面/锥体、底座。两类锥均可能方底，底座只用于占地与避障，不单独决定锥体类别。先在真实 ROI 验证规则法，证据不足输出 unknown；若真实数据下混淆明显，再以人工标注 ROI 训练轻量分类器，不替换可靠的网格几何链。

地图保存格位、锥体类别、分类置信度、底座形状、轮廓参考坐标系、证据帧和访问状态。显示层在格内画圆锥/方锥符号并附实测轮廓证据。高于地面的锥体轮廓经过地板单应性会受高度影响，不能当精确地面占地尺寸；精确避障需要底座轮廓或已知实体尺寸。地图类别和轮廓以观测为准，不用类别符号假冒真实形状测量。
