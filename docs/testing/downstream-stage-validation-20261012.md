## 范围与隔离

- 新增 `auv_runtime_stage_validation`，仅在 `BUILD_TESTING` 构建，未加入安装/部署清单。生产 `auv_runtime` 不编译测试命令，已有虚拟串口测试检查它拒绝这些命令。
- 测试程序只允许 DEBUG、真实解析后的数字 `/dev/pts/N`、手动 ARM 和关闭 HTTP，拒绝物理 UART 及含路径跳转的伪 PTY。所有运行均使用模拟相机和虚拟 MCU，没有操作实机。
- 用已知合成场景的冻结九宫格作为前置条件。重定位/四锥入口另提供上浮后的状态；退出入口再提供四锥已访问状态。前置机体状态与压力在被测阶段开始前保持，进入阶段后只按实际解码的 UART 目标积分运动。
- 不向 Runtime 注入位姿、ARM 确认或控制完成事件。上浮成功仍需压力样本；四锥成功仍需实际 `CONE_VISITED`；退出成功还检查模拟真实机体整体出界。每个案例独立进程，前一阶段失败不会阻止之后案例。
- 原局部模拟内参保持 fx=fy=250；另设 fx=250、fy=130 的宽垂直视角合成参考，所有投影和 YAML 内参一致，仍不能看到完整外框。这不是实机标定修改，更不是当前硬件验收。
