# 建图与遍历验证执行手册

2026-10-10。标签 tag16h5 / ID18、黑边 138 mm、格距 820 mm、现有矫正已由用户确认现场验证，不重复采集标定板。深度计位置为 [-0.16,0.02,-0.05] m。以下区分现场测量与开发工作；不授权自动 ARM 或运动。

## 1. 传感器无效标记与水平基准（设备开启后，无动力）

1. 保持 DISARM、八路中立，记录启动后约 60 秒的 STATUS、IMU、DEPTH 遥测及实际固件版本。
2. 分别核查 IMU sequence/时间持续更新、数值有限；DEPTH valid=1、值有限、传感器序号持续增长、样本 age 不超过配置门限。串口仍有 STATUS 不代表传感器在更新。
3. 分解 error_flags：bit1 为 required sensor invalid，bit3 为 hardware kill active。历史值 10=2+8，两项独立；急停有效时保留对应位，不能为了清零解除安全保护。追查无效位究竟来自 IMU、深度、样本超时还是上层安全输入，不掩盖位。
4. 机体按设计水平面固定，使用水平尺判断真实水平，静置后执行驾驶台岸上水平校准。须收到匹配 sequence 的成功 ACK，并看到新 STATUS bit3（水平已校准）置位；此处 STATUS 位与 error_flags 位不是同一字段。
5. 检查校准后 roll/pitch 接近零；人工轻微俯仰/横滚确认符号与机体坐标一致，回到水平后读数可恢复。记录实际误差和噪声，不用未确定的统一阈值宣称通过。该参考在 MCU 重启后清除，需重新执行；不改变偏航原点。

输出：遥测文件、错误位来源表、校准 ACK/STATUS、水平基准与 IMU 符号记录。通过条件：必需测量有效且新鲜，水平请求被 MCU 确认，静态和人工姿态变化相符。

## 2. 深度与视觉几何基准

1. **深度零点**：确认 M10/固件是否已进行归零。传感器感压口在实际水面高度、机体静止时记录 30–60 秒原始读数，取稳定段中位数与波动范围作为零点依据。不可把“机体中心在水面”直接当“感压口在水面”；不重复在 MCU 与 Runtime 两处扣除零点。
2. **水深**：在任务区域用尺/测绳独立测水面到地板的垂直距离，记录区域及水位。不是最大允许作业深度 1.2 m，也不是深度传感器当前读数。Runtime `pool_depth_m` 填该距离；`depth_zero_m` 与 Runtime 接收到的实际数据口径一致。
3. **机体与传感器关系**：水平时感压口比中心低 5 cm，中心深度=传感器深度-0.05 m。机体倾斜时用姿态旋转后的偏移修正，不固定减 5 cm。人工放到至少两个已知深度核对单位、符号和偏移。
4. **视觉角点定义**：820 mm 是节点/管线中心间距，三格中心线跨度 2460 mm。检测输出若是管外缘或底座角，不应直接套中心线坐标。开发侧在样图叠加节点中心、对应编号及像素坐标，确认世界点与图像点指向同一实体位置。
5. **阶段成像模型**：逐阶段记录相机、尺寸、原图/矫正图、裁切缩放、K/D 与版本。已矫正帧使用相应有效 K 和零畸变，原图用原 K/D；显示录像 1440×1080 不直接套采集 320×240 的 K。若相机整个任务始终浸水，不能仅因进入“surface”阶段就套空气模型；是否需要不同模型由实际光路/配置决定。先检查参数对应和已知点重投影，不要求重做已确认的水下标定。

输出：零点统计、水深实测、角点示意、阶段模型表。通过条件：已知位置深度与视觉投影在约定误差内一致，算法无重复归零/矫正。

## 3. 标签未解码样本（离线开发）

1. 从已导入人工可见帧减去自动 ID18 命中帧，输出待复核清单。按每个候选时间前后约 1 秒、每 0.1 秒抽帧，保留原始帧号；对剪辑点分段，不认为运动连续。
2. 每帧检查标签四角是否都在图内、遮挡/反光、运动模糊、最短边像素长度和透视压缩；记录可见与可解码两种标签状态，无法辨认 ID 标 uncertain。裁切帧不要求强行解码。
3. 用固定真值和同一版本分别比较默认、增强、阈值实验，记录新增命中、丢失命中、错误 ID、不可见帧误检、连续检测稳定性和耗时。不能只报最好命中数。
4. 参数选择后在目标 C++ OpenCV 版本重跑；当前 Python 5.0 比较不能代替 C++ 4.10。另留未参与调参片段作回归，避免只适合这段录像。

## 4. 同版 C++ GridMapper / ConeDetector 回放（离线开发）

1. 构建与 Runtime 相同核心库，回放适配器直接读 MP4/帧索引，不走再次去畸变的旧入口。逐帧保存算法版本、图像空间、候选角点、黄边方向、轮廓、格位、类别、置信度、拒绝原因及耗时。
2. 当前完整外框算法在局部图中可能持续拒绝，这属于正确边界；统计原因，不能因此改为成功。若人工提供四点做分类实验，明确标为人工几何输入，不能当自动建图通过。
3. 将可观测锥与真值圆锥 (3,1)/(2,1)、方锥 (3,2)/(3,3) 对比。未完成格位关联时先比较局部锥类别，不能填全局格号。分别标注锥体和底座，方底不能单独判方锥。
4. 报告类别混淆、未知比例、误检、错误格位、黄边误判与轮廓示意；模型是否可用以实际可观测片段为依据。

## 5. 局部管线/接头识别与节点关联（新增开发）

1. 在真实样图标注管中心线、L/T/十字接头、黄边和瓷砖干扰。先开发候选检测并输出叠加图，验证不会把瓷砖网直接当比赛网格。
2. 用接头拓扑、管宽/颜色、已知格距与跨帧投影一致性组建局部节点图；每个节点保留观测帧和不确定度。
3. 通过黄色边/边界拓扑确定朝向和索引；AprilTag 提供重复地标，但标签相对网格的位置仍需实际观测关联，不能凭 ID18 猜格位。
4. 对重复网格保留多个候选关联，检验一格平移、90° 旋转、锥遮挡等冲突。没有唯一解时输出 ambiguous，不能生成绝对位姿。局部绝对定位需足够分布良好的已知节点，单条线不够。

## 6. 地图累积与定位融合（新增开发）

1. 局部观测只更新其覆盖区域；为每格保存已观测范围、类别票数、轮廓证据、位置误差与时间，未观测保持 unknown。
2. 下视地板特征给短时位移，IMU/深度用于姿态与米制尺度；剔除锥体、黑边、机构和非地板特征。新标签/已关联节点提供绝对修正，融合同时保存来源与不确定度。
3. 设置可配置的位姿帧龄、最大无锚点时间、最大不确定度和创新残差门限；超限停止任务推进并报告原因，不按指令积分假装实测位置。
4. 离线/模拟注入：纹理不足与漂移、错一格关联、不同地标冲突、断流和恢复、乱序/旧时间戳、上浮后旧阶段位姿。应拒绝错误更新，过期停止，恢复须新证据；新阶段不可直接继承旧有效位姿。
5. 四个锥的位置与形状均有观测证据后才冻结地图、规划访问。地图坐标与路线参考系一致，记录实际进入节点而非发送指令即完成。

## 7. 逐帧空格标注与遍历覆盖

空白=未标注，unknown=已看但无法判断；empty 只用于对应整格清楚且确实无锥的画面。已知其余五格实际为空仍不能给遮挡或画外格填可见空。补标时无需重填全部 314 帧，优先使用能观察到管接头、黄边或锥形状的关键帧及附近连续区间。

遍历不再检查“前视每帧看到完整九宫格”。人工搬运/后续受控测试沿路线记录：局部地标何时可用、里程计何时可用、两者同时失效多久、回访是否关联同一节点、重定位误差是否满足格位与避障余量。若连续无可靠约束超过门限，系统应停下重观测；这才是局部方案的覆盖验收。

顺序：先离线标签与候选几何 → 局部关联与融合测试 → Linux 完整回归 → 设备无动力基准检查 → 受控水池闭环。
