# 局部语义地图累积验证

2026-10-10：新增 `LocalMapAccumulator` 与现有规划地图的转换接口。当前为核心源码，尚未接入 Runtime 感知线程，不代表已经实现局部定位融合。

输入必须包含唯一关联的网格坐标系、阶段编号、相机编号、帧序号和时间戳。遮挡或裁剪的格子不能投票为空；未知观测保持未知。每类需要三个独立有效帧，多个类别同时获得足够证据时保持冲突，不以多数票掩盖关联错误。轮廓保存坐标系，计数饱和以避免长时间运行溢出。

阶段切换保留同一地图的语义，但重置相机帧序列并拒绝上一阶段时间戳；地图标识改变不能静默合并。地图完成需要九格都有有效类别、没有冲突、锥数符合要求。不会根据已知场地摆放补全地图。

## 尚缺的闭环

局部管接头候选需要通过瓷砖排除、拓扑匹配、地标或连续视觉运动来唯一关联至网格；只有此后才能输入本模块。还需实现地标修正与短时下视里程计，以及漂移、断流、重定位冲突的端到端故障测试。不得用人工格位、命令运动或放宽完整四角门代替这些环节。
