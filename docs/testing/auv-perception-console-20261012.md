# AUV 驾驶台感知检查

入口为独立 AUV Runtime 的 `/dashboard/#perception`；旧 `/` 页面增加了跳转链接。保持 ROV 独立入口，不改变固件、UART 所有权、任务门控或相机采集职责。

## 看什么才算观察到了

| 页面信息 | 含义 |
|---|---|
| 双摄画面能播放 | 相机有图，不代表算法识别 |
| 绿色标签框及实际 ID | 当前选定标签相机完成解码；非目标 ID 仍显示但标为非目标。单帧解码与任务稳定触发分开显示 |
| 橙色轮廓 | 图像中的颜色分量，可能只是条纹，不直接视为圆/方锥 |
| 局部节点、关联假设 | 节点只有唯一关联后才可映射到规范网格；歧义、传感器缺失、未验证几何显式显示原因 |
| 定位证据有效 | Runtime 最新位姿本身有效且未过期，标注独立源帧、阶段模型、地标/短时里程计来源；不是 ARM 许可 |
| 累计九宫格 | unknown / empty / circle / square，保留证据冲突。描边仅表示当前整格可见，累计地图不是当前完整视野 |
| 地图冻结 | 不等于四锥访问或离开九宫格已经完成 |

无动力人工搬动时不必 START 或 ARM 即可检查解码。需要局部米制关联时仍要求实际传感器输入和验证过的几何；页面不会解除这些门，也不会在未检测目标时补造空格。相机看不见整个外框不应被当作相机故障。

## 接口与资源

`GET /api/perception` 返回 `auv.perception.v1`、当前诊断帧及 JPEG data URL、独立标签帧、局部观测与累计格位、最新 Runtime 位姿。读取只启用短时诊断观察窗口，不 START、ARM 或更改配置。关闭页面后约 3 秒停止新增诊断绘图；叠加图最多 2 Hz、宽度最多 800 px、JPEG 最多 256 KiB，页面约 1 Hz 拉取。同一缓存帧生成轮廓，不重复打开摄像头。

诊断图和控制位姿各有帧号/时间，不能将低频图的帧号当作最新控制位姿帧号。标签也有独立来源相机与帧号。标签、位姿新鲜度分别按配置检查；图超过 1.5 秒隐藏，未知格不变成 empty，位姿过期不保留绿色有效状态。旧服务 404 显示需要更新 Runtime，不自动改用模拟。

“保存感知快照”只在浏览器下载 JSON，包含显示用 JPEG 与来源元数据；不是连续录像，也不能补回精确传感器采样时刻。原始双摄记录仍由既有记录器负责。
