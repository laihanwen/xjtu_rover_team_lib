## 本轮源码

- `LocalGridDetector`：按已验证相机模型、同步姿态/深度和现场格距投影地板；检测局部白管/黄管方向和接头，检查实测格距、可见分支及黄色分支。重复内部网格保留多解，红色遮挡区域不当作缺失分支，矫正边界使用有效像素掩码。
- `metric_landmark_pose`：PnP 接受多个已关联管中心接头，不需要假造完整外框四角。检查共线、有限值、重投影、水平地板几何、传感器偏移和高度一致性；原四角接口保留其原有几何及方向门。
- `LocalMappingPipeline`：关联结果唯一后才生成局部地图观测；整格不可见保持 unknown，条纹拆成多个显著红色组件时拒绝类别，不补全锥体轮廓。相邻观测可用新鲜米制位置与方向对重复格网作唯一关联；不唯一或跳变继续拒绝。
- `LocalPoseFusion`：局部地标位姿配合短时下视里程计；默认最多 1 秒，配置上限 2 秒。检查里程计会话、时间、速度与地标修正连续性。独立融合序号不混用双摄原帧序号；里程计结果带非地标标记，不能单独完成表面重定位。
- Runtime：任务一视觉循环接入局部地图累积、局部 PnP 和短时融合。阶段变化清空融合锚点，语义地图只在同一地图坐标系内保留；新阶段下视里程计重新等待新帧，保持 MCU 深度零点口径。冻结地图保存局部节点、单元来源相机/帧号/时间和轮廓。
- A2 模拟夹具：两路合成摄像头都从同一 UART 目标积分得到的机体状态生成，替换静态下视视频。Runtime OpenCV 内部线程默认 1、允许配置 1–4；控制看门狗、定位新鲜度和速度跳变限制没有放宽。

局部算法依赖水平地板、可观测管中心、白管/黄管颜色和格距。它是需验证的规则算法，当前不宣称已解决真实瓷砖干扰或圆/方锥准确率。无法观测可信管网、只有无参照重复内部十字、模糊/遮挡或高度模型不符时保持拒绝。

## 配置与隔离

任务一模板新增：

```yaml
local_mapping:
  enabled: false
  navigation_verified: false
  odometry_budget_sec: 1.0
  empty_floor:
    verified: false
    minimum_support: 0.95
```

空格判定新增独立的可见地板 HSV 模型：没有来自真值素材的已验证颜色范围时保持 unknown，不以“没检测到红色”直接判空。模型范围不猜填，运动配置还要求地板证据已验证。

开启局部路径还要求完整 IMU 转换、匹配并已验证的下视阶段模型和 A2 前置。启用运动另需局部导航验收标记；不自动设置该标记。不把用户对矫正显示的确认误作完整新导航管线验收。

当前独立 ROV 的默认配置未开启新路径，ROV 驾驶台、串口桥与固件本轮未改动。Runtime 二进制也未替换，不能把新默认线程数称为已部署性能优化。

## 离线入口

新增 `auv_local_mapping_replay`，完整 Linux 与便携构建均加入目标；输入为原生尺寸、未剪辑相机录像和显式帧级遥测，不接受把屏幕裁切图套用相机 K。

```sh
auv_local_mapping_replay runtime-offline.yaml front.avi frame-telemetry.yaml output
```

Runtime 离线配置须关闭运动、自动启动和自动 ARM。帧记录格式如下，数值由实际日志转换，不使用示例填充值：

```yaml
camera: front                 # 或 down
image_space: rectified        # 或 raw；raw 只矫正一次
frames:
  # 每项由同一会话的真实帧/遥测关联产生：
  # frame: 原视频从 0 开始的帧号
  # stamp: 图像采样时间，秒
  # telemetry_stamp: 对齐后的遥测采样时间，秒
  # phase: underwater 或 surface
  # valid: 传感器有效标记
  # roll_deg / pitch_deg / yaw_deg / depth_m: 实际测量
  []
```

采样时间必须单调，遥测与图像相差不超过 0.15 秒。程序只读取文件，输出逐帧 CSV、接头示意图、单元类型/可见性/轮廓 YAML；没有真实里程计输入的此入口不宣称验证完整融合或任务控制。旧屏幕剪辑素材没有同步遥测，仍只能承担语义候选和人工轮廓验证，不能补造深度运行米制回放。
