# 多帧局部建图与绕场扫描：2026-10-12

本轮在已有局部定位修复的工作区上实现覆盖累计，没有部署、烧录、连接 Pi 或实机运动。验证时为未提交工作区，随后按用户要求与分段验证源码一并提交上传。完整任务的通过情况与功能实现分开记录。

## 实现

- 对每格的 176×176 像素内部区域建立固定 16×16 覆盖网格，排除管线边框；每个小区域必须完整落在有效图像掩码内才能增加可见票。
- 空格需要每个小区域在至少 3 个独立、同地图坐标系、关联唯一且通过融合检查的帧中得到已验证空地模型支持。重复帧、过期帧和跨阶段旧帧不能补票；未知区域不默认为空。
- 红色目标碎片、模型前景和已观测非管线的非空地证据会阻止判空。已知管线与重采样边缘只弃权，不当作空地，也不直接当作障碍物。
- 完整锥体轮廓及其 3 像素周围支持区域可见时，可在整格未入镜的情况下提供分类票，仍要求高置信度和多帧确认。裁剪轮廓不分类；本轮没有实现将多个不完整轮廓拼成完整目标。
- 状态和只读感知页增加 `coverage_fraction`、`empty_support_fraction`；“当前可见”改为局部可见。覆盖 100% 不代表空地验证通过。冻结地图记录逐区域可见票、空地票和阻止判空的证据。
- Runtime 与离线局部回放使用一致的累计配置。`local_mapping.coverage.required_views` 默认为 3，允许 3–10，不允许降低既有三帧确认要求。

## 绕场一周

既有 `observation_search.waypoints_m` 支持闭合航点序列：测量的安全外围路径航点，最后回到路径起点。新增闭合路线完成/耗尽回归检查，没有新增绕过定位门控的控制入口。

实机模板仍保持 `enabled: false`、`corridor_calibrated: false`、`waypoints_m: []` 和运动关闭。具体航点必须按预 ARM 原点的 X 前/Y 左坐标测量，结合机体尺寸、池壁与锥体净空；不能直接套用模拟场地坐标。

外围一圈不能保证中间格子可见，也不能消除重复网格定位歧义。路线结束后仍未确认的格子保持未知，当前会停止并报告扫描耗尽；自动根据覆盖图规划补扫路线尚未实现。允许补扫的位置应另行测量为安全走廊。
