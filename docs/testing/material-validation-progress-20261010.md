## C++ 回放运行方法与未验证边界

在具备本项目 OpenCV C++ 开发库的环境，通过根 CMake 构建 `auv_task_video_replay`。命令为：

```bash
cmake --build build-native --target auv_task_video_replay -j 3
build-native/core/auv_core/auv_task_video_replay '前.mp4' replay-front 1
```

入口当前采用单黄边/白边诊断默认参数，报告中必须注明，不能冒称与现场所有阈值一致。输出不计算米制位姿、不接入 UART、不把局部格号当已确认全局关联。当前 Windows C++ 缓存 OpenCV_DIR-NOTFOUND，旧 yaml-cpp 路径指向已不可用的其他工作区；本次入口尚未编译运行，同版 C++ 识别验证仍未通过。Python cv2 5.0 不替代 C++ 依赖。
