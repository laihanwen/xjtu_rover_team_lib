# 原生系统测试策略

更新：2026-10-11。默认入口为根 CMake / CTest，不要求 ROS、TF 或 rosbag2。

## 离线与隔离测试

- 串口协议编码、解码、CRC、兼容性与有效性/新鲜度检查。
- 同版 C++ 真实录像回放：标签、管网、黄边、锥体类别/轮廓、逐帧可见性及拒绝原因。
- 地图累积、冲突/歧义、未知格、路线约束和任务阶段切换。
- 虚拟串口动态 Runtime 闭环与故障注入：断流、重复帧、漂移、错误关联、跨阶段旧位姿。完整外框与局部路径分别验收。

## 无动力联调与水池验收

无推进器动力或可靠固定后，核验默认 DISARM、中立输出、心跳/控制看门狗、急停、通信及实际 IMU/M10 传感器失效行为。当前没有漏水传感器，不宣称相关实机检测能力。

通过软件与无动力检查后，依次验证深度/航向、视觉建图、上浮重定位、四锥访问和离网格。保持机体与摄像头浸没，净空以实测为准。运动请求需显式通过安全门；故障后不能自动重新 ARM。

## 证据与结论

每轮保存运行标识、提交/源码快照、固件及 Runtime 哈希、有效配置、标定版本、原始视频帧号/时间、遥测、事件、地图、路线与实测轨迹。先备份到 PC，凭据脱敏。不同设备单调时钟不能直接相减。
