# 测试策略

## 无硬件测试

- ROS interface 生成与 lint
- 串口帧编码/解码黄金向量
- 录制视频上的视觉回归测试
- 语义地图与路径规划确定性测试
- Mission FSM 状态转换测试

## 台架测试

- STM32 心跳超时与 DISARM
- 无桨条件下的 PWM 中性值和饱和限制
- IMU、深度、漏水和电池异常注入
- Pi 重启、串口断开和命令超时

## 水池测试

- 单自由度深度与航向保持
- 相机标定与 TF 验证
- 分阶段任务测试后再执行完整 Mission

每次水池测试应保存 rosbag2、事件日志、配置快照、固件版本、模型版本和 Git commit。
