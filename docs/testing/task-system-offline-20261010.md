# 2026-10-10 任务系统离线构建记录

## 本轮实现

ROV / AUV 保持独立固件与服务。A2 模板通过 `vision.apriltag_camera: front` 使用前视识别标签；其他模板保持默认下视。识别事件记录相机、帧序号、采样时间和证据图片。无新帧不增加稳定票数，禁用前视时拒绝选择该源。比赛标签尚未确认，因此模板不擅自将比赛规格改成练习用 ID 18。

水下建图与上浮后的前视定位使用各阶段模型。上浮完成清空度量位姿、格位有效标记和就绪状态；视觉处理完成后再次检查任务阶段和感知代次，跨阶段旧结果不能写回。状态输出增加位姿帧序号、时间、阶段、重定位边界和稳定票数，便于日志核查。

新增 `runtime/test/a2_closed_loop.py` 使用真实 Runtime 进程、虚拟 MCU PTY 和根据 UART 速度积分生成的双摄画面。覆盖标签 → 建图 → 中心对准 → 上浮 → 前视重定位 → 四锥访问；另一个场景缺少表面观测，必须 FAULT，不能进入遍历。上浮后故意保留短时水下成像，检查旧位姿不能授权横向运动；有效表面位姿时间必须晚于重定位边界。合成相机为垂直朝下以确保全图覆盖，不能替代真实 45° 前视可见性验收。该测试源码已加入 CTest，尚未完成新版完整 Linux 执行。

## 已确认的相机几何

机体 X 向前、Y 向左、Z 向上；前视位置 (0.15, 0.03, 0.02) m，俯角 45°；下视 (0.09, 0.01, -0.06) m，垂直向下。见 [安装参数](../../hardware/camera-mounting-20261010.yaml)。旋转矩阵使用前视图像正立、无额外偏航/横滚及下视图像上方朝前的安装约定；这部分需装配核对，不能视为新测得的全部外参。几何测试覆盖矩阵正交性、45° 朝向及相机偏移对机器人位置恢复的影响。

用户确认当前畸变矫正已经验证可行。本轮保留既有 K/D，记录确认来源，不再要求采集标定板。这个确认不等同于全部深度偏移、池深、运动方向、表面模型和连续导航均已验收；未知项继续阻止运动。所有实际配置仍关闭运动和自动 ARM。
