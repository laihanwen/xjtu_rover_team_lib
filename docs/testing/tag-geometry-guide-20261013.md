# 标签几何验证向导

入口：`/dashboard/geometry.html`，从标签驾驶台面板进入。该页面仅 GET 状态与相机快照，无 START/ARM、参数写回或运动接口。

## 操作

保持 INIT/DISARM、运动关闭、机体水平固定。标签为 tag16h5 / ID18 / 黑色方块外边长138 mm，平放池底，使用实际水下成像。按照前视中央/左侧/右侧、下视中央/左侧/右侧六个位置验证。

以机体几何中心量到标签黑色方块中心，输入前方X、左侧Y、向下距离，单位cm。前/左为正，后/右为负；向下距离输入正值。不要从镜头位置或标签边缘起量。下视图像方向与机体方向不能直接等同，按照实际机体左右摆放。

每位置记录3秒、至少8个独立帧，比较均值与尺量值。初始建议容差3 cm，可调整；不是已经验收的导航标准。评估使用三维位置误差范数及最大轴抖动，不只看某一轴。重复帧不补票，断线/ARM/会话或参数变化/无效观测会作废该次采集，结果与无效尝试可导出JSON。

完成六个位置后导出证据，复核偏差和方向一致性，再决定是否更新生产标定。页面不会自动打开 geometry_verified 或自主运动门。预览与数值异步，证据按数值帧号记录，不声称预览为对应帧图片；PC接收墙钟不是MCU采样时刻。

## 诊断隔离

Runtime 为每摄像头提供独立 geometry_probe：只在 debug、INIT、DISARM、运动关闭时可用。使用现有生产PnP、像素质量、旋转和重投影检查，仅在局部配置副本中允许测距计算，输出标签机体坐标与下视居中修正量。后者不作为实测标签坐标；诊断观察对象不进入 TagDockTask，不改变原始 cfg。

生产观察在 geometry_verified=false 时仍拒绝控制。诊断重投影成功不能单独证明外参、尺量坐标或尺度正确。网页导出相机K/D/版本、实测安装变换、会话、帧号、坐标均值、误差和抖动。
