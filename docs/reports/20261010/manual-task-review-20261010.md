素材支持分阶段策略：先以完整多帧观测确认目标和场地方向，保持未知格未知；接近期间使用下视局部观测作为辅助，无遮挡且几何已验证后才能交接；到位先停平移，再用新观测停留确认；丢失定位停止平移，不凭视频演示顺序盲走。前视建图与连续定位迁移仍需实测外参、可见性和相应源接口，不在本次宣称已闭环。

## 本次实现

`SurfaceRouteExecutor` 在 waypoint 到位容差内停止平移，等待已有稳定时间和新位姿证据确认。退出容差后恢复现有控制；节点确认、禁止重复进入、超时及失效检查保留。新增两项断言验证到位停移及重复帧不能推进。

新增 `tools/auv/review_manual_task.py`：离线扫描双摄 tag16h5/ID18 可见性，保存每帧来源、视频时间、检测 ID、边界和边长，并导出指定墙钟区间的原始遥测和证据摘要。只评估导出图像空间，不套用原始 K/D，不二次去畸变，不写已验证标记，不控制实机。结果可导入日志分析台。

本机找到既有 OpenCV 4.10 与 yaml-cpp 开发依赖，使用全新 Windows 便携构建目录验证 12/12 CTest 通过（包括 A2、标签任务与录像回放）；离线分析器无效/过期数据回归通过。该结果不等于 Linux Runtime 编译或水池闭环验收。ROV 固件与遥控运动算法未改动。未烧录、部署或放开运动门控。
