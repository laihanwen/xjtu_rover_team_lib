## 当前代码核对与待完成项

1. `GridMapper` 已识别四种单黄边，并将四角循环重排，统一黄边在内部地图底边。原生 `test_white_edge_grid` 已有四方向合成场景测试。本次没有重跑，不能据此宣称最新版本通过。
2. `runtime.cpp` 地图 JSON 保存重排后的图像角点、类别、轮廓和 `bottom_edge: yellow`，但没有显式保存重排前黄边编号、图像空间/相机/帧序号及出发区—标记—网格关系。必须补齐后才能作为完整场地方向证据；图像上下也不能直接等同场地上下。
3. `ConeDetector` 对颜色分割后的外轮廓做圆度/多边形分类。如果方底也进入分割，圆锥可能误判为方锥。需真实两类锥多角度近照和前视录像验证，采用锥体证据；证据不足保留 unknown，不能按“两个圆两个方”倒推。
4. 现有建图、常规标签触发、PnP 与遍历仍主要使用下视。用户已说明下视看不全图，因此图纸到位并未解除视觉闭环缺口。前视建图与连续定位迁移需要固定俯角的可靠内参、机体外参和连续可见性录像；前视试验内参不能用于导航。
5. `metric_grid_pose` 中 `abs(down[2]) < 0.8` 检查的是网格平面法向在**机体**坐标中的方向，包含相机到机体旋转，并非直接检查镜头是否朝下。正确前视外参可补偿俯角，不能仅因相机俯视 45° 删除该门控。
6. 四锥路径应继续遵守已访问锥格不可重复进入；确认格内安全路径与机体空间，而不是直接瞄准锥顶。遍历受控试验还需要相机连续定位、机体尺寸、锥顶净空与水平运动标定。

当前 AUV 模板继续保持运动关闭、未验证标定；独立 ROV 固件和原驾驶台不因本次场地资料核对改变。
