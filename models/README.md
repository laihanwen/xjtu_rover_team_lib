# Model registry

模型权重通常较大，不直接提交到 Git。`manifests/` 保存可审计的模型元数据，实际文件放在被忽略的 `artifacts/`，并通过 GitHub Release、对象存储或团队约定的位置分发。

每个发布模型的清单至少包含：

- 唯一名称和版本
- 任务与类别列表
- 训练数据版本
- 框架与版本
- 输入尺寸和预处理方式
- 原始权重、ONNX/NCNN 文件名
- 每个文件的 SHA-256
- 下载地址或 Release tag
- 关键评估指标和目标硬件基准

在权重管理方案确定前，不启用 Git LFS 或 DVC，避免仓库声明了团队机器尚未安装的工具。
